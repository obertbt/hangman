# ADR-0005: 正規化は「吸収するが推測しない」

- 状態: 採用
- 日付: 2026-08-12

## 背景

依頼書41章は、表記ゆれを吸収せよと言いつつ
「曖昧な場合は警告する」「勝手に推測しすぎない」とも言っている。

この線引きをどこに引くかを決めておかないと、実装者ごとにぶれる。

## 判断

**「表記の違い」は吸収する。「情報の不足」は推測しない。**

| 種類                 | 例                     | 扱い                                 |
| -------------------- | ---------------------- | ------------------------------------ |
| 同じ情報の別の書き方 | `3年生` → `3`          | **吸収する**（警告も出さない）       |
| 同じ情報の別の言語   | `Forward` → `FW`       | **吸収する**                         |
| 情報が足りない       | `4/15`（年が無い）     | 補える基準があれば補い、**必ず警告** |
| 情報が足りず補えない | `4/15`（基準年も無い） | **エラー**                           |
| 知らない語           | `センター`             | **エラー**（勝手に MF などにしない） |
| 矛盾している         | 学年1年 + 入学年度2024 | **警告**（どちらも直さない）         |

## 具体例

### 吸収する（警告なし）

```
3 / 3年 / 3年生 / ３年             → 3
Forward / フォワード / FW / fw     → FW
2026/4/15 / 2026-04-15 / 2026年4月15日 → 2026-04-15
10 / 10番 / １０                   → 10
Hanako@Example.com                 → hanako@example.com
山田　花子                          → 山田 花子
```

### 補うが警告する

```
4/15（基準年 2026）→ 2026-04-15
  警告: 年の記載が無いため 2026 年として扱いました（4/15）。
```

### エラーにする

```
センター  → ポジションとして読み取れません（センター）。
            GK / DF / MF / FW / STAFF のいずれかにしてください。
2026-02-30 → 存在しない日付です。
来週の火曜  → 日付として読み取れません。
```

### 警告だけ出して、どちらも直さない

```
学年 1年 / 入学年度 2024（今 2026年）
  警告: 学年（1年）と入学年度（2024）が合いません。
        入学年度からは 3 年になります。
```

学年が古いのか、入学年度が間違っているのか、
それとも留年・休学があったのか、機械には分からない。
**どちらかに寄せて直すと、間違った情報が「正しく」保存されてしまう。**

## なぜこの線引きか

過去データの移行は一度きりだが、失敗すると取り返しがつかない。
「たぶんこうだろう」で入ったデータは、後から見ても
それが推測だったと分からなくなる。

一方で、表記ゆれを一切吸収しないと、
移行前にスプレッドシートを手で整える作業が発生する。
それでは「コピペするだけ」という目標が成り立たない。

**人が5秒で判断できることは吸収する。
人でも迷うことは人に返す。**

## 実装上の決まり

正規化関数はすべてこの形を返す。

```ts
type NormalizeResult<T> = { ok: true; value: T; warning?: string } | { ok: false; error: string };
```

- `warning` を付けたら、必ずプレビューに表示する
- `error` の文言には「どう直せばよいか」を含める
- 例外を投げない（1行の失敗で全体を止めないため）

## 実際にあった落とし穴

全角を半角に直す処理で、長音符「ー」(U+30FC) をハイフンに変換していた。
結果、`キーパー` が `キ-パ-` になり、ポジションを読み取れなくなった。

テストで見つかった。全角記号を扱うときは、
**片仮名の一部である文字を巻き込んでいないか**を必ず確認する。
