# Web画面の使い方と、外出先からのアクセス設定

日記とタスクをブラウザから閲覧する画面です。Botと同じプロセスで動くため、24時間稼働の設定はそのまま流用できます。

```
ブラウザ ──> ミニPC上のWeb画面 ──┬─> GitHub API（日記・タスク）
                                  └─> R2（画像は表示のたびに一時URLを発行）
```

日記の実体はこれまでどおりGitHubとR2にあり、**Web画面はデータを一切保持しません。** 画像も非公開バケットのままで、ページを開いたときに数分だけ有効な署名付きURLを生成して表示します。

---

## できること

| 画面 | 内容 |
|---|---|
| 月の一覧 | その月の記録がある日を一覧表示。前月・翌月へ移動できます |
| 日ごとの表示 | その日の投稿を時刻順に表示。添付画像もその場で表示されます |
| タスク | 未完了のGitHub Issueを一覧表示 |

閲覧専用です。編集や削除はできません（記録はDiscordから、タスクを閉じるのはGitHubから行います）。

---

## 1. 有効にする

`.env` に3行追加します。

```
WEB_ENABLED=true
WEB_PASSWORD=ここに8文字以上のパスワード
WEB_PORT=8787
```

`WEB_PASSWORD` は**必須**です。設定せずに `WEB_ENABLED=true` にすると、起動時にエラーで止まります（日記が誰でも読める状態になるのを防ぐためです）。

依存関係を追加してから、Botを再起動します。

```powershell
cd C:\Users\tabata\Documents\hangman
git pull
.venv\Scripts\activate
pip install -r requirements.txt
```

タスクスケジューラで「終了」→「実行する」で再起動し、ログを確認します。

```powershell
Get-Content logs\bot.log -Tail 20 -Encoding UTF8
```

```
Web画面を起動しました: http://0.0.0.0:8787
```

この行が出れば起動しています。

## 2. ミニPCから開いてみる

ブラウザで次のURLを開きます。

```
http://localhost:8787
```

パスワードを入力してログインすると、当月の一覧が表示されます。

## 3. 同じWi-Fi内のスマホから開く

ミニPCのIPアドレスを調べます。

```powershell
ipconfig
```

「IPv4 アドレス」の値（例: `192.168.1.23`）を使い、スマホのブラウザで開きます。

```
http://192.168.1.23:8787
```

つながらない場合はWindowsファイアウォールでブロックされています。管理者PowerShellで次を実行してください。

```powershell
New-NetFirewallRule -DisplayName "hearth-life web" -Direction Inbound -LocalPort 8787 -Protocol TCP -Action Allow -Profile Private
```

> `-Profile Private` を付けているのは、**自宅などの信頼済みネットワークでのみ**開放するためです。`Public` を含めると、カフェなどのネットワークに接続したときにも開いてしまいます。

---

## 4. 外出先から見られるようにする（Tailscale）

外出先から使うために**ポート開放（ポートフォワーディング）はしないでください。** インターネット全体に日記が晒され、パスワード1枚だけが防御になります。

代わりに **Tailscale** を使います。自分のデバイス同士だけをつなぐ仮想的な内部ネットワークを作る仕組みで、個人利用は無料、ルーターの設定変更も不要です。**インターネットには一切公開されません。**

### 4.1 ミニPCにTailscaleを入れる

1. https://tailscale.com/download/windows からインストール
2. 起動し、Googleアカウントなどでログイン
3. タスクトレイのTailscaleアイコンから、割り当てられたIPアドレス（`100.x.x.x` の形式）を控える

### 4.2 スマホにTailscaleを入れる

1. App Store / Google Play で「Tailscale」をインストール
2. **ミニPCと同じアカウント**でログイン

これで、スマホとミニPCが同じ仮想ネットワークに入ります。

### 4.3 外出先から開く

スマホのTailscaleをONにした状態で、ブラウザから次を開きます。

```
http://100.x.x.x:8787
```

（`100.x.x.x` は手順4.1で控えたミニPCのTailscale IPです）

外出先の回線でも、自宅のミニPCにつながります。

### 4.4 常時つながるようにする

- **ミニPC側**: Tailscaleは既定でWindows起動時に自動起動します。タスクトレイに常駐していることを確認してください
- **スマホ側**: Tailscaleアプリの接続をONのままにしておくと、必要なときすぐ開けます（OFFにすると `100.x.x.x` にはつながりません）

---

## セキュリティについて

| 項目 | 状態 |
|---|---|
| インターネットへの公開 | **なし**（Tailscale経由のみ） |
| パスワード | 必須・8文字以上。5回間違えると5分間ロックされます |
| ログインの保持 | 既定30日間（`WEB_SESSION_HOURS` で変更可）。Bot再起動でログアウトされます |
| 画像 | 非公開バケットのまま。表示のたびに短時間の署名付きURLを発行 |
| 検索エンジン | `noindex` を指定済み（そもそも到達できません） |

**注意点**として、自宅Wi-Fi内での閲覧（手順3）は暗号化されていないHTTP通信です。同じWi-Fiに他人がいる環境では、Tailscale経由（手順4）でのアクセスをおすすめします。Tailscaleの通信は暗号化されます。

---

## 設定項目

| 変数 | 既定値 | 説明 |
|---|---|---|
| `WEB_ENABLED` | `false` | `true` でWeb画面を有効化 |
| `WEB_PASSWORD` | なし | ログインパスワード（有効時は必須・8文字以上） |
| `WEB_PORT` | `8787` | 待ち受けポート |
| `WEB_HOST` | `0.0.0.0` | 待ち受けアドレス。`127.0.0.1` にするとミニPC本体からのみアクセス可 |
| `WEB_SESSION_HOURS` | `720` | ログインの保持時間（時間単位。既定30日） |

## 困ったときは

| 症状 | 対処 |
|---|---|
| ログに `Web画面は無効です` と出る | `.env` の `WEB_ENABLED=true` が反映されていません |
| 起動時に `WEB_PASSWORD の設定が必要です` で止まる | `WEB_PASSWORD` を8文字以上で設定してください |
| `ModuleNotFoundError: fastapi` | `pip install -r requirements.txt` を実行してください |
| ミニPCからは開けるがスマホから開けない | ファイアウォール設定（手順3）を確認してください |
| 外出先から `100.x.x.x` につながらない | スマホのTailscaleがONになっているか、ミニPCのTailscaleが常駐しているか確認してください |
| 画像が表示されない（×印になる） | 一時URLの期限切れです。ページを再読み込みしてください。`SIGNED_URL_EXPIRY_SECONDS` を延ばすこともできます |
| ページが502エラーになる | GitHubまたはR2への接続に失敗しています。`logs\bot.log` を確認してください |
| Botは動くがWeb画面だけ落ちた | Web画面が停止してもBot本体は動き続ける設計です。ログの「Webサーバーが停止しました」を確認し、Botを再起動してください |
